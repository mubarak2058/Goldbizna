INDEPENDENT SYSTEM RESCUE PAGE

Get your system back to normal.

Use this page when the POS, Settings or dashboard freezes, loads endlessly, or behaves strangely. This recovery page works separately from the main app and does not need Firebase to open.

Data protection: Recovery actions below do not delete sales, inventory, customers, savings, staff accounts or Firestore records. The cache-clean action only clears cached website files and unregisters this site's service workers. It does not clear local storage or IndexedDB.
Recovery centre ready. Choose the safest action for the problem.

1. Return to normal

Reload the current recovery page, then reopen your normal workspace.

Open dashboard

2. Repair cached website files

Use if the site keeps showing an old broken version after an update. Clears website cache only; your business records stay untouched.

3. Check connection

Check whether this device is online and whether the browser can reach the website host.

4. Open a clean workspace

Open the POS or Settings in a separate tab, without changing or resetting business data.

Open POSOpen Settings

5. Full browser restart

If the browser tab itself is frozen and buttons do not respond, close the frozen tab or browser app, reopen it, and return to this recovery page.

6. Return to Master Control

Go back to the protected platform management area after the workspace responds normally.

Open Master Control

Important: A web page cannot forcibly repair a browser tab whose JavaScript engine is completely frozen. In that case, close the frozen tab/app and reopen it. Do not use browser options such as “Clear site data” or “Clear storage” as they may remove locally stored information.
